# StudySprint

StudySprint is a modern JEE preparation platform built to help students revise smarter and faster.

## 🚀 Features

- 📘 Physics Formula Hub
- 🧪 Chemistry Formula Hub
- 📐 Mathematics Formula Hub
- 🔍 Smart Search
- ⏱️ Pomodoro Timer
- 📊 Study Tools
- 📱 Responsive Design
- 🌙 Dark Mode

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vercel

## 🎯 Vision

To build one of the best free study platforms for JEE aspirants with notes, revision tools, calculators, AI-powered study features, and more.
